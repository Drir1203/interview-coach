# 产品需求文档 (PRD)

## 1. 产品定位

> **i面试** — 你的 AI 面试教练。不是看面经的平台，而是帮你管理自己的面试记录、AI 分析每一次表现、系统性提升面试能力的工具。

## 2. 目标用户

| 画像 | 核心需求 | 付费意愿 |
|------|---------|---------|
| 应届生（校招） | 高频面试，需要系统性管理 + 快速提升 | 中高 |
| 社招跳槽（3-8年） | 同时面多家，需要记录对比 | 中 |
| 转行者 | 需要大量练习 + 反馈闭环 | 高 |

## 3. 商业模式

```
Free Tier
  ├─ 5 场面试记录
  ├─ 基础 AI 评分
  └─ 基础 Dashboard

Pro Tier（¥29-49/月）
  ├─ 无限面试记录
  ├─ AI 深度复盘（逐题详细分析 + 优化回答）
  ├─ 薄弱项追踪 + 雷达图
  ├─ AI 模拟面试
  └─ 数据导出
```

## 4. 功能清单

### 已完成 ✅

| 模块 | 功能 | 说明 |
|------|------|------|
| 认证 | 注册/登录/登出 | Auth.js + JWT，密码 bcrypt 加密 |
| 数据库 | PostgreSQL | 云端存储，跨设备同步 |
| 面试 CRUD | 新建/编辑/删除/列表 | 完整表单：公司/岗位/轮次/标签/备注/问题列表 |
| 面试检索 | 搜索 + 状态筛选 | 按公司/岗位搜索，草稿/已记录/已复盘 Tab |
| 面试结果 | 标注通过/未通过/等待 | 点击即切换，Dashboard 统计联动 |
| AI 复盘 | 逐题评分 + 优化回答 | 支持 Mock 模式（无需 Key）和真实 Claude API |
| 录音转写 | 实时录制 + 文件上传 | MediaRecorder 录制 / 上传 mp3/wav/m4a/ogg |
| 数据看板 | 统计卡片 + 雷达图 + 趋势图 | 4 项核心指标 + 5 维能力画像 + 评分走势 |
| 公司看板 | 按公司聚合 | 各公司面试次数/平均分/面试列表 |
| AI 模拟面试 | 多轮对话式面试 | 配置公司/岗位/轮次 → AI 提问 → 用户回答 → 生成报告 |
| 深入分析 | 跨公司对比 / 薄弱项追踪 / 趋势下钻 | 3 Tab：对比雷达图、薄弱项排序、可筛选趋势 |
| CSV 导出 | 面试记录导出 | 含问题/AI评分的完整 CSV |
| 面试日历 | 月历视图 | Dashboard 嵌入，标记有面试的日期 |
| 暗色模式 | 手动切换 | Sidebar 底部切换按钮，localStorage 持久化 |
| 移动端适配 | 汉堡菜单 + 响应式 | 手机端侧栏折叠，遮罩点击关闭 |
| 加载/错误/空状态 | 全页面覆盖 | 骨架屏/加载动画/错误提示/空状态引导 |

### 未开发 ❌

| 模块 | 功能 | 说明 |
|------|------|------|
| 体验 | PDF 导出 | 暂只支持 CSV |
| 多端 | 微信小程序 | 已开发：登录/总览/面试列表/详情/新建/模拟面试/设置，共 8 页 |
| 多端 | 离线数据同步 | 暂不支持 |

## 5. 技术栈

| 层 | 技术 |
|---|------|
| 前端 | Next.js 16 + TypeScript + Tailwind 4 + shadcn/ui |
| 后端 | Next.js API Routes |
| 数据库 | PostgreSQL + Prisma ORM |
| 认证 | Auth.js (NextAuth v5) + JWT |
| AI 复盘 | DeepSeek → DashScope Qwen → Anthropic Claude → Mock |
| 语音转写 | Qwen3-ASR-Flash (Aliyun DashScope) |
| 浏览器压缩 | FFmpeg.wasm（分段 60s） |
| 部署 | Ubuntu + Nginx + PM2 |

## 6. 用户旅程

```
注册/登录
    │
    ├── 记录面试 → 录入问题 → AI 复盘 → 查看报告
    │                                └── 标注结果（通过/未通过）
    │
    ├── 录音 → 自动提取 QA → AI 复盘
    │
    ├── 模拟面试 → AI 面试官 → 结束 → 评分报告
    │
    └── Dashboard ← 所有数据自动汇总
```
