01 — 诊断摘要

核心判断：问题不在“丑”，在于自相矛盾 + 无记忆点

商业化平台的第一观感不由单一元素决定，而是系统一致性。当前最大风险不是某个设计不好看，而是同一品牌在不同触点呈现彼此矛盾的面貌。

CRITICALLogo 两套并轨

浏览器标签页 favicon（public/logo.svg）是黑色 #18181b；而产品内 Logo 与 PWA 图标是靛蓝 #6366f1。逐像素采样确认 PNG 图标均为 indigo 系，仅 SVG favicon 回归黑色。标签页是商业化首屏，等于品牌自己先穿帮。

HIGH模板化背景噪声

营销 Hero 与登录页使用「indigo→violet 双色渐变 + blur-3xl 光斑」，是当前 AI 生成式 SaaS 的默认配方，辨识度低、廉价感强，与“教练”的信任感相悖。

MED缺一个“独占符号”

对话泡 + 对勾的通用组合，在满屏 chat-AI 产品里没有排他性。用户记不住“AI 面师”，只记得“又一个蓝色对话机器人”。

MED主题色本身是健康的

靛蓝 #6366f1 在暗色下转 #818cf8，配浅 slate 中性色——底子是好的，接近 Linear / Notion 的克制方向。修复重点是守住它，而不是推翻它。

02 — 竞品语境

生产级平台怎么处理“工具 + AI + 教练”

参照做法可借鉴
Linear极简几何 monogram，字距收紧，几乎不用渐变符号的克制与自信
Stripe一色识别 + 大规模留白，图标在彩底/白底都可读图标系统的双态一致性
Notion / Raycast黑白中性字标为主，AI 能力靠排版语言而非霓虹降低“AI 感”反而更可信
多邻国 / 得到 / 扇贝用拟人角色或中文字建立情感记忆教练品类的温度与陪伴
Cursor / v0高饱和单一强调色 + 去装饰化背景背景让位给内容

结论：竞品都在“减法”。我们的 Step 1 也应是减法——先止血矛盾，再重画符号。

  • 暗色模式同规则（indigo-400/10）

04 — Logo 方向 · A / B / C

三个候选，代表三种取舍

以下为概念稿，非最终图形；用于确认方向后再精修。

A

逐级对话

Stairline

两个对话泡错落上升——每一次对话，都让下一次站得更高。把“聊天”与“进阶”焊进同一个手势。

App 图标位
AI 面师
favicon 16 彩底 32

为什么是它

对话 = 品类（陪练是对话产品）；阶梯 = 价值（越练越强）。一个图形同时回答“你是做什么的”和“你带给我什么”，叙事最完整。

风险与代价

  • 双泡造型偏常见，需在比例/切角上做出差异
  • 放弃了对勾这一既有资产，等于换新叙事
  • 负空间需要精细打磨
B

中文「面」字标

Mian · Letterform

用一个汉字当图腾：面试是“面对面”，教练是“当面指点”，复盘是“面面俱到”。字即品牌，天然独占、天然跨端一致。

圆角方窗版
师 · AI 面师
字标 32 浅底版本

为什么是它

中国市场的“独占捷径”：英文 chat-bubble 符号全球同质，中文单字却能一句话讲清品类。面字又自带“认真对待”的仪式感，贴合教练而非玩具。

风险与代价

  • 需定制字型或重绘字形，直接套系统字体反而显廉价
  • 汉字笔画在 16px favicon 下的可读性需专项测试
  • 「AI 面师」与单字「面」的关联要靠字标组合建立
C

回声对勾

Echo Check

把既有“对勾”资产极简化为两次复沓的回声——每场复盘，都为同一种能力再落下一个勾。保留资产，做最小几何进化。

双勾回声 · App 图标位
AI 面师
彩底 32

为什么是它

风险最低：用户对“打勾”已有心理账户（答对、掌握、通过），不推翻既有认知。回声 / 复沓把“复盘 + 反复训练”的动态价值装进静态符号，极简、可延展、16–512px 都稳。

风险与代价

  • 与“满屏 AI 对勾图标”仍有几分神似，差异靠比例与切角
  • 叙事密度低于 A，偏“好看的安全牌”

05 — 决策建议

给创始人一句实话

推荐在 A（逐级对话）与 B（中文面字标）之间选：C 是最安全的止损，但止损不等于建品牌。商业化平台需要只有你能用的符号——A 给“练得越多越强”的成长叙事，B 给“面师 = 面对面”的中文独占。若短期靠增长、需极致克制，选 C 无妨；若目标是“被记住”，优先 A 或 B。

选定方向后：完整 SVG 源文件 → favicon / PWA / apple-touch 全套生成 → 深浅双态与 16–512px 可读性验证 → 字标组合与规范。
