## 一、竞品全景

### 国内市场

| 竞品 | 定位 | 核心功能 | 定价 | 用 AI 的方式 | 短板 |
|------|------|---------|------|------------|------|
| **牛客网** | 校招求职综合社区 | 题库/笔试/面经/内推 | 会员 ¥20-30/月 | 后加的 AI,弱 | 是"刷题+看面经",**不是个人成长系统**;不管理真实面试 |
| **面试鸭** | 程序员面试题库 | 面试题 + AI 解析 | 会员 | AI 答疑 | 单点问答,无复盘闭环 |
| **智面星** | AI 模拟面试 | AI 提问 + 录音回答 | 按次/机构 | 对话式 AI | 只模拟,不记录真实面试,无追踪 |
| **通用大模型**(豆包/文心/通义/Kimi) | 通用 AI | 让 AI 当面试官闲聊 | 免费 | 单次对话 | **无结构化、无记录、无复盘、无长期追踪** |
| **新兴 AI 面试 App** | 零散 | 大多 = AI 对话模拟 | — | 单次问答 | 同质化严重 |

### 国际市场

| 竞品 | 定位 | 优势 | 短板 |
|------|------|------|------|
| **Interviewing.io** | 匿名真人互面 | 真实反馈 | 重社交,国内水土不服 |
| **Pramp** | 免费 peer mock | 真人互动 | 无系统性复盘 |
| **Big Interview** | 课程+题库+AI 模拟 | 内容体系成熟 | 贵($199/年) |
| **Yoodli** | AI 口才反馈 | 语速/填充词分析 | 只练表达,不懂面试 |
| **Google Interview Warmup** | 免费 AI 模拟 | 逐题反馈 | 无记录无追踪 |
| **HireVue 等** | **企业端** AI 面试 | B2B 大规模初筛 | 站在求职者对立面 |

**关键趋势**:企业端(HireVue)已在批量用 AI 面试初筛求职者 —— 这意味着**求职者端更需要 AI 来准备**。

### 竞品普遍没做好的 = 市场空白

1. **真实面试的完整记录与复盘闭环** — 竞品全是"练习"(模拟),没人系统管理你的**真实面试**。
2. **长期成长追踪** — 跨多场面试的能力画像、薄弱项如何演化,竞品几乎没有。
3. **多轮/多公司面试管理** — 同时面多家、一面到终面的策略。
4. **AI Agent 深度个性化** — 竞品的 AI 都是"单次问答",没有记忆、不会主动跟进、没有工作流。

## 二、我们 vs 竞品

### 差异化定位(已经是对的)

> **不是"看面经/练模拟"的平台,而是"管理你真实面试 + AI 复盘闭环 + 长期成长"的系统。**

这是竞品都没占的位置。

### 现有优势

- ✅ 独特的"真实面试记录 → AI 复盘"闭环(竞品没有)
- ✅ 录音转写(FFmpeg + DashScope ASR)、AI 多模型复盘(DeepSeek → Qwen → Claude 降级)
- ✅ 能力雷达图、评分趋势、薄弱项追踪、公司看板
- ✅ AI 模拟面试、CSV/PDF 导出
- ✅ 技术栈现代,数据模型(Interview/Question/UserSkillProfile)已支持成长画像

### 短板(下一步要补的)

| 短板 | 说明 |
|------|------|
| **没有 AI Agent** | 目前是"单次调用",不是"有记忆的教练" |
| 没有个性化学习计划 | 不会根据薄弱项主动排练习 |
| 移动端不完整 | 小程序功能有限 |
| 无品牌/流量 | 没有牛客那样的社区 |
| **商业化未上线** | 还没付费墙、没支付、没运营 |

## 三、核心差异化:AI Agent + AI 工作流

### 定位升级

> 从 **"面试复盘工具"** → **"你的私人 AI 面试教练 Agent"** —— 它**记住你、规划你、推进你**,而不只是回答问题。

### 具体 AI Agent 能力

**1. 记忆型教练 Agent(核心)**
- 记住你所有面试、每个薄弱项、目标岗位、行业方向
- 每次对话都有完整上下文(不是冷冰冰的单次问答)

**2. 面试前工作流(Agent 主动做)**
- 输入目标公司/岗位 → Agent 自动生成:该岗位**押题清单** + **个人薄弱项强化题** + **预测问题**
- 自动排"今天练什么"的计划

**3. 面试后工作流(自动闭环)**
- 录音/上传 → 自动转写 → AI 复盘 → 更新能力画像 → **生成本周成长报告** → 自动安排下次练习
- 用户零操作,全自动

**4. 求职进度工作流**
- 追踪正在面的每家公司进度(一面/二面/终面/HR面)
- 到终面主动给终面策略;面挂了给补救方案

**5. 多 Agent 架构**
- 面试官 Agent(提问)→ 复盘 Agent(分析)→ 教练 Agent(规划)→ 求职策略 Agent(跟进)
- 四个 Agent 协作,形成"记录→复盘→规划→跟进"闭环 —— **竞品完全没做的**

### 技术可行性

- 项目里已有自研 Agent 经验(crossborder-ai 的 ReAct + Function Calling Agent)
- 现有 AI 服务链(DeepSeek→Qwen→Claude)可升级为 Agent 编排
- 现有数据库模型(Interview/Question/UserSkillProfile)已足够支撑"记忆 + 画像"
- **实现难度可控**:不是从零造,是在现有基础上加 Agent 编排层

## 四、商业化路线

### 阶段一:快速变现(MVP,2-4 周)

- 上线付费墙:Free(5 场)+ **Pro ¥29-49/月**(PRD 已定义)
- 接支付(微信/支付宝)
- 先把"真实面试复盘"这个独特定位做起来

### 阶段二:AI 教练 Agent 套餐(差异化护城河)

- **Pro 升级为"AI 教练 Agent"套餐 ¥49-99/月**
- 按 Agent 使用量或套餐区分(基础复盘 vs 深度教练)
- 这是竞品没有的,是核心卖点

### 阶段三:B2B 放大(长期)

- 面向求职培训机构、校招机构、企业 HR 的 B2B 版本
- 批量账号 + 企业看板(看学员/候选人的能力画像) + API
- B2B 客单价高(几千到几万/年)

### 增长

- 面试干货内容(公众号/小红书/知乎)
- 校招季活动(9-11 月、3-4 月)
- 求职社群,用"成长报告"做传播(用户晒成长曲线)

## 一句话总结

竞品在做"题库和模拟",我们已经在做"真实面试的管理与复盘",这是空白位。下一步用 AI Agent 把"记录→复盘→规划→跟进"变成全自动闭环,就是别人抄不走的护城河。然后按"个人付费 → AI 教练套餐 → B2B"三步商业化。
