# 小程序名称候选方案

> 背景：原名「i面试+」因涉及**通用词**（"面试"）被微信审核拒绝。需改用**有辨识度、不直接用通用词**的名称。
> 平台核心价值：**AI 面试教练**——记录面试、AI 复盘、模拟面试、押题、成长报告。

## 当前选择

- ~~AI 面霸~~（**已被占用**）
- ~~AI 智面~~（**已被占用**）
- ~~灵犀智面~~（**企业商标被拒**：灵犀为阿里/讯飞注册商标）
- ~~AI 面神~~（**定位不符**：平台 slogan 是"你的 AI 面试教练"，"神"太夸张）
- **✅ 选定：`AI 面师`** ⭐（2026-08-04 提交审核）
  - 面师 = 面试导师，贴"AI 面试教练"定位
  - 已同步小程序内品牌文案（登录页标题/关于页/README）

## 八、教练定位类（贴合 slogan"你的 AI 面试教练"）

| 名称 | 解读 |
|------|------|
| **AI 面师** | 面师 = 面试导师（自造缩写），师=教练 |
| **AI 面伴** | 面伴 = 面试伙伴/陪练，陪伴感 |
| **面策 AI** | 面策 = 面试策略，AI 出谋划策 |
| **AI 面语** | 面语 = 面试怎么说话 |
| **面引 AI** | 面引 = 引导你的面试 |

> 统一用"面"字打头（暗指面试、不含通用词）+ 师/伴/策/语/引 表达教练角色

## 七、原创短语类（无商标风险，最后一批）

| 名称 | 解读 |
|------|------|
| **一面成神** | 一次面试成神，有梗有抱负 |
| **offer 方舟** | 载你上岸拿 Offer 的方舟 |

| **面战室** | 面试的练战场 |

## 改名操作路径（需在微信公众平台操作）

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com)
2. 设置 → 基本信息 → 修改名称
3. 提交新名字审核（注意改名有次数限制）
