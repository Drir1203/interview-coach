# AI 视频面试迭代 —— SDD 行为规格

> 状态：规格已确认（2026-08-25）｜方案：**阿里云 AI 面试（IMS 智能体）**
> 需求方：用户（产品owner）｜实现：SDD + TDD

## 1. 背景与目标

现有「AI 模拟面试」是纯文字/语音形态。本次迭代目标：**AI 面试官以真人形象 + 语音的方式开口提问，模拟真人面试**。

**选型结论（2026-08-25 调研）**：用阿里云「AI 面试」（智能媒体服务 IMS 智能体）而非自组装数字人：
- 开箱即用：面试官 LLM + STT/TTS + 通话交互 + 防作弊 + 音视频/转写归档全打包
- LLM 支持自研接入（OpenAI 规范）→ 可接 DeepSeek/千问/我们的回退链
- 数字人形象可配（VideoAgent 多形象/数字人节点，P2 开通）
- 比自组装开发量小得多，成本更低

## 2. 能力点

| # | 能力 | 验收标准 |
|---|---|---|
| C1 | **AI 面试官开口提问** | 面试官按提示词设定的角色/岗位逐题提问，语音自然（纯语音版）|
| C2 | **真人形象（P2）** | 数字人/VideoAgent 形象 + 指定 TTS 音色，画面+声音同步 |
| C3 | **语音回答** | 候选人自然语音作答（ASR 实时转写），按住说话/停止短语模式可选 |
| C4 | **优雅降级** | 阿里云未配置/欠费/异常 → 切回现有纯文字模拟面试，不中断 |
| C5 | **面试报告** | 面试结束取转写归档 → 现有报告链生成评估报告 |
| C6 | **背景注入** | 押题/岗位/简历/用户能力画像作为面试官提示词，面试更针对性 |

## 3. 需求场景

- **S1 主流程**：用户进模拟面试 → 选公司/岗位/轮次 → 启动阿里云 AI 面试 → 面试官按注入的岗位+背景逐题提问 → 用户语音作答 → 多轮 → 结束 → 拿转写 → 评估报告。
- **S2 降级**：阿里云未开通/欠费/异常 → 自动切回现有文字模拟面试，提示「AI 面试服务暂不可用，已切换文字模式」。
- **S3 成本控制**：纯语音版优先（¥0.1/分钟）；免费用户限制场次/时长。
- **S4 接入阻断**：未登录用户不能发起（登录墙已有）。

## 4. 技术架构

```
┌──────────────────────────────────────────────────────────┐
│ 前端 practice/session（AI 面试模式）                       │
│  阿里云 ARTC 客户端 SDK（WebRTC 通话/视频）                │
└──────────────┬───────────────────────────────────────────┘
               │ /api/video-interview/{start,status,end}
┌──────────────▼───────────────────────────────────────────┐
│ 后端（Node）                                              │
│  组装提示词（人设+岗位+候选人背景/简历/能力画像）           │
│  创建 AI 面试会话 → 返回客户端 ARTC 参数                    │
│  结束取转写归档 → 现有报告链                               │
│  未配置 AK → C4 降级文字模式                               │
└───────────────────────────────────────────────────────────┘
```

**关键实现点**
- 服务端：`@alicloud/ims*` 创建/管理 AI 面试会话；组装面试官提示词（复用 `buildUserContext` 的能力画像 + 押题 + 岗位）
- 前端：阿里云 ARTC 客户端 SDK 拉取通话/视频流；通话结束返回转写 → 展示报告
- 环境变量：`IMS_ACCESS_KEY_ID` / `IMS_ACCESS_KEY_SECRET` / `IMS_AGENT_ID`（或工作流模板）/ `IMS_APP_ID`；未配置 → C4 降级
- 面试数据落库：关联现有 Interview/SubscriptionOrder 体系（面试记录、Pro 限额）

## 5. 分阶段

| 阶段 | 内容 | 依赖 |
|---|---|---|
| P0 | 用户开通：IMS「AI 实时互动」+ 创建 Agent/工作流模板 + 拿 AccessKey/AppId | 用户操作（控制台）|
| P1 | 纯语音 AI 面试：后端创建会话 + 前端 ARTC 通话 + 降级 + 转写报告 | 代码 + 用户开通 |
| P2 | 数字人形象：VideoAgent/数字人节点 + 音色 + 形象选择 | P1 |
| P3 | 优化：免费用户场次限制 / 成本监控 / 面试历史归档展示 | P2 |

## 6. 成本

- AI 智能体：纯语音 ¥0.014/分钟（≈¥0.1）、视频通话 ¥0.0502/分钟（≈¥0.36）；ARTC 双向按分钟（极低）；数字人节点（P2，需开通相芯/灵境）
- 单场面试（10-15 分钟）：纯语音 ≈ **¥1.5-2**；视频版 ≈ **¥5-8**
- LLM：预置免费；自研/非预置按模型计费（DeepSeek 按 token，很便宜）
- 新用户 7 天免费体验可验证

## 7. 非目标（本次不做）

- 不做防作弊深度定制（用平台默认）
- 不做小程序端视频面试（先 Web，IMS 支持移动 H5 可后补）
- 不做面试官动作编排（VAML 高级动作）

## 8. 风险

- 阿里云 API/价格可能调整（以控制台为准）
- WebRTC 通话对网络要求高；移动端原生浏览器兼容性一般（建议桌面 Chrome）
- 面试官 LLM 由阿里云托管，grill/追问逻辑需通过提示词控制
- IMS SDK 接入细节需以真实 API 文档为准（WebFetch 被网络策略挡，实现时用 SDK 类型定义核对）
