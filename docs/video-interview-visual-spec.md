# AI 语音面试 · 视觉真实感升级 —— SDD 行为规格

> 状态：**待用户确认**（2026-09-02）｜类型：纯前端视觉增量（零额外成本）
> 需求方：用户（产品 owner）｜前提：现有 AI 语音面试（阿里云 IMS + ARTC）已上线可跑

## 1. 背景与目标

现有「AI 语音面试」通话页是一个居中的圆形 Brain 图标 + 字幕 + 两个按钮，**视觉简陋、不像真实面试**。用户反馈：没有"真人面试"的感觉。

本次目标：在不换后端、不加第三方付费服务的前提下，把通话页升级为**视频会议式沉浸体验**——面试官虚拟形象（说话有口型动画）+ 面试间场景 + 可选开启自己的摄像头，让用户有"真的在开视频面试"的临场感。

**选型**：纯前端增量，不依赖数字人/视频流（C2 原案保持独立、可后续再做）。形象用**浏览器内绘制的 SVG 面试官**（无版权/无外部资源/离线可用），说话动画由引擎已有的 `agentStateChanged`（3=讲话）驱动，**不碰音频流**，稳定可测。

## 2. 能力点

| # | 能力 | 验收标准 |
|---|---|---|
| V1 | **面试官虚拟形象** | 专业面试官 SVG 形象（上衣+领带/西装风），浏览器内绘制，无外部图片依赖；四态视觉：连接中(转圈)、聆听(呼吸)、思考(…点点)、讲话(口型动画) |
| V2 | **说话动画** | `agentStateChanged` 3(讲话)→ 口型开合 + 声波动画；2(思考)→ 思考动效；1(聆听)→ 轻微呼吸；未知/未连接→ 静止 |
| V3 | **会议式双画面** | 面试官大画面（含形象+名牌+状态点）+ 用户摄像头小画面（**默认关**，用户可开；权限拒绝→隐藏开关不阻断通话）；整体会议 App 布局 |
| V4 | **面试官名牌与状态** | 名牌显示「面试官 · 岗位 · 公司」+ 通话状态点（连接中/进行中）+ 计时 |
| V5 | **实时字幕强化** | 面试官提问字幕置底呈现（沿用 `agentSubtitleNotify`），讲话时字幕高亮 |
| V6 | **控制条** | 底部会议式控制条：静音 / 摄像头开关 / 挂断，按钮带状态反馈，禁用逻辑与现有一致 |
| V7 | **零回归** | 阿里云会话生命周期（init/call/挂断/finalize/降级/转写落库）**一行不改**；`END_PHRASES` 自动收尾、`errorOccurred` 处理不变 |

## 3. 需求场景

- **S1 进入**：用户点「AI 语音面试」→ 连接中：面试官形象 + 旋转动效 + 「正在接通面试官…」→ 接通：形象名牌点亮 + 状态点变绿 + 摄像头开关出现（默认关）。
- **S2 通话**：面试官讲话 → 形象口型开合 + 声波动画 + 字幕实时滚动；面试官思考 → 思考动效；聆听 → 呼吸动画 + 静音状态展示。
- **S3 自己出镜**：用户点摄像头开关 → 授权后右上角出现自己的画面（镜像）；再点关闭 / 权限拒绝 / 挂断 → 移除画面，通话不受影响。
- **S4 结束**：用户挂断 / 面试官宣布结束 → 现有 finalize 逻辑不变 → 转写落库 → 报告页。
- **S5 降级**：阿里云未配置/欠费/失败 → 现有文字模式提示（「AI 语音面试暂不可用，已切换到文字模式」）不变。

## 4. 技术方案

- **文件**：
  - 新增 `src/components/interviewer-avatar.tsx`：SVG 面试官形象（`isTalking`/`isThinking`/`isListening` props 驱动口型/点头/呼吸，CSS keyframes 动画）。
  - 新增 `src/lib/interview-visuals.ts`：纯函数 `visualStateFromAgentState(agentState?) → {talking, thinking, listening, connected}` 映射（**可单测**）。
  - 新增 `src/components/self-camera.tsx`：可选摄像头画面（`getUserMedia` + `<video>` 镜像，挂断自动停流）。
  - 改 `src/components/video-interview-call.tsx`：布局改为会议式双画面 + 名牌 + 控制条；接 `agentStateChanged` 驱动形象动画；其余逻辑不动。
- **口型动画**：以 `agentStateChanged`（3=讲话）为信号，**不读取音频能量**（SDK 未暴露音频流，且 state 信号更稳）。
- **摄像头**：`getUserMedia({video:true})`；权限拒绝/无设备 → 隐藏开关 + 不报错；挂断/卸载时 `track.stop()`。
- **背景**：Tailwind 渐变 + 暗色面试间氛围（虚化面板、细网格），复用品牌靛蓝设计系统 token。

## 5. 非目标（本次不做）

- 不做真数字人/实时视频流（C2 原案，独立后续，需第三方付费服务）。
- 不改阿里云会话/API/落库/配额/报告链任何一行。
- 不采集或分析用户语音内容。
- 不做小程序端（Web 先行）。

## 6. 成本与风险

- **成本：零**（纯前端，无第三方服务、无按分钟费用、无外部图片资源）。
- 风险：
  - SVG 形象观感主观，可能需要迭代样式（用户可随时要求换风格/性别）。
  - 摄像头依赖浏览器权限；非 HTTPS（本地 http 下）`getUserMedia` 会被禁 → 开关自动隐藏。
  - 动画性能：CSS keyframes + 极轻量 JS，`requestAnimationFrame` 限制声波频率，不引入重库。

## 7. 验收与测试

- 单测（`tests/unit/interview-visuals.test.ts`）：
  - `visualStateFromAgentState`：3→talking / 2→thinking / 1→listening / undefined→idle / 异常值→idle。
  - 讲话时 `talking=true` 且 `listening=false`；思考/聆听互斥正确。
- 手动验收：真实阿里云会话下，口型动画随面试官说话开合、摄像头开关、字幕滚动、挂断收尾。
- 门禁（改动必测）：vitest → tsc → `npx next build` → `bash tests/api-test.sh` 不回归。
